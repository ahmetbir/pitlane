# Pitlane Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A browser multiplayer formula racing game (Pitlane) on roomkit: one fictional track,
Race mode, bots, Arcade/Sim handling and ghost/soft/full contact chosen per room, a car setup
the physics responds to, live at `pitlane.ahmetbirinci.dev` with blue/green + CI deploy.

**Architecture:** Go authoritative server (roomkit room actor at 60 Hz, snapshots at 30 Hz)
owning a deterministic `race.Race` of 10 cars (dynamic bicycle model, spline track); TS +
Three.js client predicting its own car with a 1:1 port of the car model and interpolating the
rest; stats on a new generic `roomkit/ledger`.

**Tech Stack:** Go 1.26.8 (`github.com/ahmetbir/roomkit`, `github.com/coder/websocket` only),
TypeScript 5.8, Three.js 0.186, esbuild, Node 22 (`node --experimental-strip-types --test`).

**Spec:** `docs/superpowers/specs/2026-10-07-pitlane-design.md` (this repo). Reference
implementation for every adapter/server/deploy piece: Dogfight at
Dogfight, checked out beside this repo as `../dogfight` (read-only for this plan, except Task 2's
roomkit work, which happens in a roomkit checkout at `../roomkit`).

## Global Constraints

- Repos: Pitlane is this repo (module `github.com/ahmetbir/pitlane`); roomkit is checked out beside it at `../roomkit`.
- Go deps: only `github.com/ahmetbir/roomkit` and `github.com/coder/websocket`. Client runtime deps: `three` and `roomkit` (`git+https://github.com/ahmetbir/roomkit.git#vX.Y.Z`) only.
- While roomkit changes are unreleased: `replace github.com/ahmetbir/roomkit => ../roomkit` and `"roomkit": "file:../../roomkit"`; the controller pins tags before any push.
- Node 22 for the client (`node --experimental-strip-types --test`; Node 20 cannot run the tests).
- Determinism: no `time.Now`, goroutines, map-order iteration or global RNG in `internal/car`, `internal/track`, `internal/race`, `internal/bot`. RNG = splitmix64 seeded from room settings.
- Car step uses only `+ - * / sqrt` and comparisons; no `math.Sin/Atan/Exp` in the step (track construction and bots may use them).
- Sim tick 60 Hz, snapshot every 2 ticks, 10 cars, 3 sectors, laps ∈ {3,5,8} default 3.
- Wire protocol version `1`. Notice/refusal codes are lower snake case and must not collide with roomkit `netproto.ErrorCodes()`/`APICodes()`; refusal code `racing`.
- Local storage keys: prefix `pitlane.` (`pitlane.lang`, `pitlane.name`, `pitlane.pilot`, `pitlane.setup`, `pitlane.settings`).
- Commits: author email `55314919+ahmetbir@users.noreply.github.com`; stage files by name (never `git add -A`); never `rm -rf`.
- Every task leaves `go vet ./... && go test ./...` and (once the client exists) `cd client && npm run check && npm test` green.

## Review Focus

- A player who joins mid-race takes over a bot car at the bot's place, and leaving hands the car back to a bot (Task 9 tests both).
- Wall hits at high speed never leave a car outside the barrier or with NaN state (Task 5 and Task 7 tests: 90 m/s into a wall at 30°, 1000 ticks, finite and inside).
- Corner cutting: a lap that skips a sector does not count; a lap with > 2 s fully off track is invalid for boards but counts for the race (Task 8).
- An all-bot room (no humans) still finishes and loops grid → race → results without leaking (Task 9 runs 3 races headless).
- Setup values outside ranges, NaN/Inf inputs or a `ready` before `welcome` are clamped/refused, never crash (Task 4 Clamp test, Task 10 decode test).

Grid rules: phase Grid until (every seated human Ready and ≥ 1 human) or 30 s since the first human sat or `Start`; with no humans, 10 s then start (all-bot rooms keep cycling — needed for the lobby list to look alive and for tests). Racing: at lights out set every LapStart = tick, Lap = 0 (crossing s=0 forward completes lap 1). Finish: when the leader completes Laps; others finish on their next line crossing; Finish lasts until all finished or 45 s.
